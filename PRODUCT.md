# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Travelers, vacation planners, and adventure seekers who want to discover destinations, explore interactive maps and globes, and craft personalized travel itineraries.

## Product Purpose

Globe-Trotter empowers users to discover new places through interactive map/globe exploration and quickly generate tailored travel itineraries, making trip planning inspiring, efficient, and visual.

## Positioning

Globe-Trotter bridges geographic visual exploration directly with dynamic AI-powered itinerary building, offering a seamless workflow from destination inspiration to day-by-day travel scheduling.

## Operating Context

Web application used on desktop, tablet, and mobile devices during travel research, itinerary creation, and active trip reference.

## Capabilities and Constraints

- Framework: Next.js 16 (App Router) + React 19 + TypeScript.
- Styling: Tailwind CSS v4 with responsive layout and dark/light mode support.
- Core Features: Interactive globe/map destination discovery and AI-assisted itinerary builder.

## Brand Commitments

- Product Name: Globe-Trotter.
- Visual Craft: High-craft modern UI with fluid micro-interactions and rich aesthetics.

## Evidence on Hand

- Clean Next.js 16 scaffold ready for development in repository root (`app/page.tsx`, `package.json`).

## Product Principles

1. **Visual Discovery First**: Inspire travelers through interactive geographic exploration before asking for details.
2. **Frictionless Itineraries**: Transform interest into structured, actionable day-by-day plans effortlessly.
3. **Impeccable Craft & Performance**: Deliver fast, responsive, and beautifully themed UI across all viewports.
